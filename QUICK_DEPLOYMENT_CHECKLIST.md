## Якщо щось пішло не так

### ⚠️ КРИТИЧНО: Дані витікають між підрозділами

**ДІЯ:** Негайний відкат!

1. [ ] Зупинити всі операції
2. [ ] Виконати відкат коду: `git revert HEAD`
3. [ ] Виконати відкат БД: відновити з backup
4. [ ] Повідомити про проблему

### ⚠️ Build не працює

1. [ ] Перевірити помилки: `npm run build 2>&1 | tee build.log`
2. [ ] Видалити `node_modules` і `dist`: `rm -rf node_modules dist`
3. [ ] Переінсталювати: `npm install`
4. [ ] Спробувати build знову: `npm run build`

### ⚠️ Повільна робота

1. [ ] Перевірити, що міграція 016 застосована
2. [ ] Виконати в SQL Editor:
```sql
ANALYZE users;
ANALYZE objects;
ANALYZE hours;
ANALYZE processes;
```
3. [ ] Перевірити індекси:
```sql
SELECT tablename, indexname FROM pg_indexes
WHERE schemaname = 'public' AND indexname LIKE 'idx_%';
```

### ⚠️ Підрозділи не відображаються при реєстрації

1. [ ] Перевірити RLS політику:
```sql
SELECT * FROM pg_policies WHERE tablename = 'departments';
```
2. [ ] Має бути політика "Public can view departments"
3. [ ] Якщо немає - виконати міграцію 014 знову
