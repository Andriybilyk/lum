# 🔄 Об'єднання Керування Об'єктами та Процесами

## 📋 Що змінилось

### До
Менеджер мав **дві окремі кнопки**:
- 🔵 "Керувати Об'єктами" - для управління об'єктами
- 🟠 "Керувати Процесами" - для управління стандартними процесами

**Проблема**: Незручно - потрібно окремо керувати об'єктами, а потім окремо додавати до них процеси.

### Після
Менеджер має **одну кнопку**:
- 🎨 "Об'єкти та Процеси" - об'єднане керування

**Переваги**:
- ✅ Вибираєш об'єкт
- ✅ Одразу можеш керувати його процесами
- ✅ Простіший workflow
- ✅ Менше кліків

---

## 🎯 Як це працює

### 1. Відкриття модального вікна
Натискаєш кнопку **"Об'єкти та Процеси"** → відкривається список об'єктів

### 2. Перегляд об'єктів
- Бачиш всі об'єкти з фільтрами та пошуком
- Для кожного об'єкта відображається:
  - 📊 Статистика (години, процеси, заробіток, працівники)
  - 📈 Прогрес годин
  - 💰 Прогрес бюджету
  - 👥 Список працівників (при кліку)

### 3. Керування процесами об'єкта
**Натискаєш кнопку "Процеси →"** на картці об'єкта:
- Відкривається список процесів **тільки для цього об'єкта**
- Можеш додавати, редагувати та видаляти процеси
- Кнопка "← Назад" повертає до списку об'єктів

### 4. Інші дії з об'єктом
Для кожного об'єкта доступні:
- **📄 Звіт** - детальний звіт по об'єкту
- **📦 Матеріали** - матеріали використані на об'єкті
- **✏️ Редагувати** - змінити дані об'єкта
- **🗑️ Видалити** - видалити об'єкт

## 🗂️ Структура файлів

### Новий компонент
```

```

**Що робить**:
- Об'єднує функціонал `ManageObjectsModal` та `ManageProcessesModal`
- Два режими перегляду:

- Перемикання між режимами через стан `selectedObject`

## 💡 Ключові особливості реалізації

### 1. Два режими перегляду
```typescript
const [selectedObject, setSelectedObject] = useState<{ id: string; name: string } | null>(null);

// Рендер залежить від стану:
{selectedObject ? renderProcessesList() : renderObjectsList()}
```

### 2. Процеси прив'язані до об'єкта
```typescript
const objectProcesses = useMemo(() => {
  if (!selectedObject) return [];
  return processTypes.filter(p => p.object === selectedObject.name);
}, [processTypes, selectedObject]);
```

При додаванні процесу:
```typescript
await addProcessType({
  name: newProcess.name,
  rate: parseFloat(newProcess.rate),
  unit: newProcess.unit,
  object: selectedObject.name  // ← Прив'язка до об'єкта
});
```

### 3. Навігація між режимами
```tsx
// В картці об'єкта:
<Button onClick={() => setSelectedObject({ id: obj.id, name: obj.name })}>
  <Settings className="w-3 h-3 mr-1" />
  Процеси
  <ChevronRight className="w-3 h-3 ml-1" />
</Button>

// В режимі процесів:
<Button onClick={() => setSelectedObject(null)}>
  <ArrowLeft className="w-5 h-5" />
</Button>
```

### 4. Діалог видалення
```typescript
const [deleteConfirm, setDeleteConfirm] = useState<{
  id: string;
  name: string;
  type: 'object' | 'process'  // ← Тип для різних обробників
} | null>(null);
```

## 🎨 UX покращення

### 1. Візуальна ієрархія
- **Список об'єктів** → Широкі картки з детальною статистикою
- **Процеси об'єкта** → Компактний список з фокусом на редагування

### 2. Градієнт кнопки
Нова кнопка має **потрійний градієнт**:
```css
bg-gradient-to-r from-blue-600 via-purple-600 to-pink-500
```
Символізує об'єднання двох функцій (синій + помаранчевий = фіолетовий/рожевий)

### 3. Іконки навігації
- **ChevronRight (→)** - перехід до процесів
- **ArrowLeft (←)** - повернення до об'єктів

### 4. Хлібні крихти в заголовку
```tsx
<DialogTitle>
  {selectedObject
    ? `Процеси: ${selectedObject.name}`
    : 'Керування Об\'єктами та Процесами'
  }
</DialogTitle>
```

## ✅ Переваги нового підходу

### Для користувача
- ✅ **Менше кліків** - все в одному місці
- ✅ **Зрозуміліший workflow** - вибрав об'єкт → керуєш процесами
- ✅ **Контекст** - завжди бачиш для якого об'єкта керуєш процесами

### Для розробника
- ✅ **Менше дублювання коду** - один компонент замість двох
- ✅ **Зрозуміліша логіка** - чітка ієрархія об'єкт → процеси
- ✅ **Легше підтримувати** - всі зміни в одному файлі

## 📊 Порівняння

### Старий workflow
```
1. Клік "Керувати Об'єктами"
2. Знайти потрібний об'єкт
3. Запам'ятати назву
4. Закрити модалку
5. Клік "Керувати Процесами"
6. Додати процес
7. Вручну ввести назву об'єкта
```
**= 7 кроків**

### Новий workflow
```
1. Клік "Об'єкти та Процеси"
2. Знайти потрібний об'єкт
3. Клік "Процеси →"
4. Додати процес (назва об'єкта вже підставлена)
```
**= 4 кроки** 🎉

## 🔮 Можливі майбутні покращення

1. **Bulk операції** - додавати кілька процесів одночасно
2. **Копіювання процесів** - копіювати процеси з одного об'єкта в інший
3. **Шаблони** - зберігати набори процесів як шаблони
4. **Швидке переключення** - вибирати об'єкт без повернення до списку
5. **Історія змін** - відстежувати хто і коли змінював процеси
