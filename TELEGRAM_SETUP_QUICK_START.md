# Telegram Mini App - Швидкий старт

## Що це?

Ваш вже розроблений додаток тепер повністю інтегрований для роботи як Telegram Mini App. Користувачі можуть логувати робочі години прямо з Telegram!

## 🚀 Два режими роботи

### 1. Основний додаток - `/telegram`
```
https://yourdomain.com/telegram
```
**Повна функціональність:**
- Статус та статистика (графіки, дані за місяц)
- Детальні звіти по днях/проектах
- Налаштування профілю
- Темна тема
- Навігація внизу екрану

### 2. Швидкий логер - `/telegram/quick`
```
https://yourdomain.com/telegram/quick
```
**Швидкий доступ:**
- +30 хв, +1h, +4h, +8h кнопки
- Прогрес за місяць (160 годин)
- Офлайн синхронізація
- Мінімальний інтерфейс

## 📋 Налаштування (5 кроків)

### Крок 1: Відкрийте BotFather
В Telegram: `@BotFather`

Команда:
```
/newbot
```

- **Ім'я**: Time Tracker
- **Username**: my_time_tracker_bot (унікальне!)

**Збережіть токен!** (приклад: `123456789:ABCDefGHIjklmnopqrsTUVwxyz`)

### Крок 2: Налаштуйте кнопку меню
В BotFather:
```
/setmenubutton
[Choose your bot]
Web App
Text: Time Tracker
URL: https://yourdomain.com/telegram
```

### Крок 3: Зареєструйте Mini App
В BotFather:
```
/newapp
[Choose your bot]
```

Заповніть:
- **Short Name**: `time_tracker` (без пробілів)
- **Title**: Time Tracker
- **Description**: Логування робочих годин
- **App URL**: `https://yourdomain.com/telegram`

### Крок 4: Додайте змінні оточення
`.env` файл:
```env
VITE_TELEGRAM_BOT_TOKEN=123456789:ABCDefGHIjklmnopqrsTUVwxyz
VITE_TELEGRAM_BOT_USERNAME=my_time_tracker_bot
VITE_APP_URL=https://yourdomain.com
```

### Крок 5: Розгорніть на сервер
```bash
npm run build
# Скопіюйте папку dist на ваш сервер
```

## 🌐 Користувач оновлюється з Telegram

Коли користувач відкриває додаток, автоматично:
1. Аутентифікується через Telegram
2. Його дані беруться з `initDataUnsafe.user`
3. Профіль заповнюється автоматично (ім'я, username)
4. Не потрібна окрема реєстрація (опціонально)

---

## 🔄 Офлайн синхронізація

### Як працює

```
Користувач натискає "+8h"
    ↓
Дані зберігаються в localStorage
    ↓
Показується UI статус
    ↓
Кожні 30 сек спроба синхронізації
    ↓
Якщо успішно → ✅ Synced
Якщо помилка → ❌ Error
```

### Що потрібно для бекенду

**POST /api/telegram/sync**
```json
{
  "userId": "123456789",
  "entries": [
    {
      "date": "2024-11-14",
      "hours": 8,
      "synced": "pending"
    }
  ]
}
```

## 🚨 Розв'язання проблем

### Проблема: Mini App не завантажується
**Перевірте:**
- HTTPS включений (обов'язково!)
- URL правильний у BotFather
- Домен доступний
- Перезавантажте браузер (Ctrl+F5)

### Проблема: Користувач не визначається
**Перевірте:**
1. Відкрите в Telegram WebView (не в звичайному браузері)
2. Дані в консолі:
```javascript
window.Telegram?.WebApp?.instance?.initDataUnsafe?.user
```

### Проблема: Дані не синхронізуються
**Перевірте:**
1. Бекенд endpoint `/api/telegram/sync` працює
2. Кінцева точка повертає 200 OK
3. localhost квота для localStorage достатня

## 🔐 Безпека

### Перевірка користувача на бекенді

```typescript
// Всі дані з Telegram мають бути верифіковані!
const telegramUserId = req.body.userId;
// НЕ довіряти цьому напряму - перевірити токен!
```

Telegram забезпечує:
- Криптографічну сигнатуру `hash` у `initData`
- Захист від підробок
- HTTPS тільки
