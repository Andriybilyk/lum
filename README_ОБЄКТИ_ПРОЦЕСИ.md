# 🎯 Об'єднане Керування Об'єктами та Процесами

## 📌 Швидкий огляд

**Що це**: Об'єднане меню для керування будівельними об'єктами та їх процесами.

**Для кого**: Менеджери будівельних проєктів

**Навіщо**: Спростити додавання та редагування процесів для об'єктів

---

## 🚀 Швидкий старт

### Як користувач
1. Відкрити додаток як Менеджер
2. Натиснути **"Об'єкти та Процеси"**
3. Обрати об'єкт
4. Натиснути **"Процеси →"**
5. Керувати процесами для цього об'єкта

### Як розробник
```bash
# Файл компонента
/app/src/components/manager/ManageObjectsAndProcessesModal.tsx

# Використання
import ManageObjectsAndProcessesModal from './ManageObjectsAndProcessesModal';

<ManageObjectsAndProcessesModal
  open={isOpen}
  onClose={() => setIsOpen(false)}
/>
```

```

  - Неактивний: Gray (#9ca3af)
```

## 🐛 Відомі обмеження

1. **Старі компоненти не видалені**
   - `ManageObjectsModal.tsx` досі існує
   - `ManageProcessesModal.tsx` досі існує
   - Можуть використовуватись в інших місцях

2. **Глобальні процеси**
   - Процеси тепер прив'язані до об'єктів
   - Для глобальних використовуй старий компонент

3. **TypeScript помилки в supabaseService**
   - Pre-existing помилки
   - Не блокують роботу
   - Потребують окремого фіксу
